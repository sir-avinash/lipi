# Lipi

A collection of reusable skills for authoring mathematical textbooks and publication-grade geometric diagrams inspired by Keenan Crane's *Discrete Differential Geometry* and *Illustrating Geometry*.

## Included Skills

- [`beautiful-diagrams/SKILL.md`](beautiful-diagrams/SKILL.md): 3D-first projection, strict stroke hierarchy, pastel shading with soft cast shadows, white-haloed math labels, and Python/`matplotlib` + inline SVG patterns.
- [`book-template/SKILL.md`](book-template/SKILL.md): Warm off-white paper (`#fdfcf8`), Tufte-style measure, `EB Garamond` / `Source Sans 3` / `JetBrains Mono` typography, theorem/remark callout boxes, MathJax 3, and Mermaid.js static GitHub Pages architecture.
